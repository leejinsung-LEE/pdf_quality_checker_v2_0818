## ✨ 구현된 주요 기능

### 1. 일반 설정
- **언어 선택**: 한국어, English, 日本語, 中文
- **테마 선택**: 다크, 라이트, 시스템
- **시작 옵션**:
  - 프로그램 시작 시 폴더 감시 자동 시작
  - 닫기 버튼 클릭 시 트레이로 최소화
  - 마지막 감시 폴더 자동 복원

### 2. 처리 설정
- **기본 프로파일**: default, quick, strict 선택
- **자동 처리**:
  - 검사 후 자동 문제 수정
  - 완료 파일 이동
- **보고서**:
  - 자동 생성 여부
  - 형식 선택 (HTML, JSON, 텍스트)

### 3. 폴더 설정
- **기본 출력 폴더**: 찾아보기 버튼으로 선택
- **완료 파일 폴더**: 찾아보기 버튼으로 선택
- 감시 폴더 안내 메시지

### 4. 인터페이스 설정
- **알림**:
  - 처리 완료 알림 표시
  - 알림음 재생
- **사이드바**: 너비 조절 (200-400px)
- **테이블 열 표시**: 8개 열 개별 표시/숨김

### 5. 고급 설정
- **처리 설정**:
  - 동시 처리 파일 수 (1-10)
  - 처리 타임아웃 (초)
- **로그 설정**:
  - 로그 레벨 (DEBUG, INFO, WARNING, ERROR)
  - 로그 보관 기간 (일)

### 6. 외부 도구 설정
- **Ghostscript 경로**: 수동 설정 및 테스트
- **pdffonts 경로**: 수동 설정 및 테스트
- **자동 감지**: 시스템에서 도구 자동 찾기
- 각 도구별 상태 표시 (사용 가능/찾을 수 없음)
