## 🔧 기술 스택

### 핵심 라이브러리
- **GUI**: CustomTkinter 5.2.0
- **PDF 처리**: pikepdf 8.10.0, PyMuPDF 1.23.8
- **이미지 처리**: Pillow 10.1.0
- **데이터**: pandas 2.1.4, SQLite3

### 외부 도구
- **Ghostscript**: PDF 변환 및 수정
- **Poppler (pdffonts)**: 폰트 분석
- **향후**: pdftk, pdfnup (판짜기용)

---

## 📊 성능 지표

### 처리 속도
- 단일 PDF (10MB): ~3-5초
- 배치 처리 (100개): ~5분
- 폴더 감시: 실시간 반응

### 메모리 사용
- 기본 실행: ~150MB
- 대용량 PDF: ~500MB (스트리밍 처리)
- 최대 동시 처리: 10개 파일

## 🚀 실행 방법

### 1. 환경 설정
```bash
# 가상환경 생성
python -m venv venv

# 가상환경 활성화 (Windows)
venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt
```

### 2. 프로그램 실행
```bash
# 메인 프로그램
python main.py

# 테스트 실행
python test_main.py
```

### 3. 외부 도구 설정
- Ghostscript 설치: https://www.ghostscript.com/
- Poppler 설치: 프로그램 내장 (poppler/ 폴더)
