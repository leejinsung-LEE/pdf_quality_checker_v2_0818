## 중요 발견사항

### 1. 하드코딩 여부 검증
**결론: 하드코딩이 아님**

검증 내용:
- 특정 파일명을 체크하는 코드 없음
- 일반적인 PDF 품질 검사 규칙을 구현
- 모든 PDF 파일에 적용 가능한 범용 검사 로직

### 2. 실제 문제점 발견
**pdffonts 출력 파싱 오류**
- "Type 1C" 폰트 타입이 공백으로 분리되어 파싱 오류 발생
- Good(G) 파일도 실제로는 폰트가 임베디드되어 있으나, 파싱 오류로 미임베딩으로 판단
- 이로 인해 모든 파일에서 "폰트가 임베디드되지 않음" 이슈 보고

## 구현된 검사 항목 및 도구

### 1. FontChecker (폰트 검사)
**사용 도구**: 
- pdffonts (poppler-utils)
- PyMuPDF (내부 분석)

**검사 항목**:
- 폰트 임베딩 확인
- Type3 폰트 검출
- 최소 텍스트 크기 검사

### 2. ColorChecker (색상 검사)
**사용 도구**:
- PyMuPDF 내부 분석

**검사 항목**:
- RGB 색상 사용 검출
- 별색(Spot Color) 사용 검출
- 잉크 도포량(Ink Coverage) 검사

### 3. ImageChecker (이미지 검사)
**사용 도구**:
- PyMuPDF 내부 분석

**검사 항목**:
- 이미지 해상도 검사
- 압축 방식 검사
- 색상 모드 검사

### 4. LayoutChecker (레이아웃 검사)
**사용 도구**:
- PyMuPDF 내부 분석

**검사 항목**:
- 재단선(Bleed) 검사
- 비균일 재단선 검출
- 대형 포맷 재단선 검사

### 5. PrintChecker (인쇄 검사)
**사용 도구**:
- PyMuPDF 내부 분석

**검사 항목**:
- 오버프린트 설정 검사
- 흰색 오버프린트 검출

### 6. AdvancedChecker (고급 검사)
**사용 도구**:
- PyMuPDF 내부 분석
- Ghostscript (계획됨)

**검사 항목**:
- 오버프린트 검사
- 16비트 이미지 검사
- JPEG2000/JBIG2 압축 검사
- ICC 프로파일 검사
- DeviceN 색상 공간 검사
- Type3 폰트 검사

## 결론

현재 시스템은 하드코딩이 아닌 실제 PDF 품질 검사를 수행하고 있으나, pdffonts 파싱 오류로 인해 모든 파일에서 동일한 이슈(폰트 미임베딩)를 보고하고 있습니다. 

이는 우연히 100% 감지율을 달성했지만, 실제로는 잘못된 감지입니다. Good 파일들은 실제로 문제가 없어야 하는데, 파싱 오류로 인해 문제가 있다고 잘못 보고되고 있습니다.
